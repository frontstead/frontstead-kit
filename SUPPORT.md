# Support

Frontstead Kit is community-supported open-source software.

## Get Help

- Read the [project documentation](./docs/README.md) and search [existing issues](https://github.com/frontstead/frontstead-kit/issues).
- For a reproducible defect in Frontstead Kit, open a bug report using the repository template.
- For a proposed product change, use the feature request template.

Include your Frontstead version or commit, Node.js version, operating system, deployment environment, relevant logs with secrets removed, and minimal reproduction steps.

Public issues are not appropriate for vulnerabilities, credentials, personal information, customer records, or licensed MLS data. Report security concerns according to [SECURITY.md](./SECURITY.md).

Maintainers cannot guarantee response times or provide individual deployment, brokerage compliance, MLS onboarding, or production operations support through the issue tracker.
