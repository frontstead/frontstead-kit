# @frontstead/tokens

Brand-neutral CSS tokens, Tailwind v4 mappings, class-name utilities, and the
build-time Frontstead theme compiler.

```css
@import "@frontstead/tokens/preset.css";
@import "@frontstead/tokens/palette.default.css";
```

Applications using `@frontstead/ui` must also register that package as a
Tailwind source because dependencies are ignored by default.
